# Sistema de Notas

Um pequeno programa em Python que calcula se um aluno foi aprovado ou reprovado com base na nota informada.

![Exemplo do Sistema](https://i.pinimg.com/564x/b3/cf/53/b3cf53b1b2ba150b49030eacc11ec146.jpg)

## Funcionalidades
- Recebe a nota do aluno
- Mostra se o aluno foi aprovado ou reprovado
- Mensagens interativas com pausas para melhor visualização

## Como rodar
1. Baixe o arquivo `sistema_notas.py`
2. Abra no terminal
3. Execute:
```bash
python sistema_notas.py
